# ISHARA — Ancient Gestures, Contemporary Threads

Welcome to the digital showroom of **ISHARA** (meaning: a gesture, a signal, a whisper of something ancient). 

The website captures a rich aesthetic direction: **"Anti-gravity meets Indian sacred art"** — where garments float, patterns tell ancient legends, and the typography evokes dusk in a Rajasthani haveli.

---

## 🎨 Design Systems & Themes

- **Colors**:
  - Deep Maroon (`#6B1A2A`) — Deep, primary ink
  - Earthy Olive (`#4A5240`) — Natural, grounded secondary
  - Mustard Gold (`#C8922A`) — Warm accentuation
  - Aged Cream (`#F5EDD6`) — Historic parchment background
  - Soft Blush (`#E8C9A0`) — Delicate highlights
  - Dark Charcoal (`#1C1814`) — Text and dark mode elements
- **Typography**:
  - Headings: *Cormorant Garamond* (High-contrast, classic serif)
  - Body: *Jost* (Modern, clean, legible geometric)
  - Taglines/Poetry: *IM Fell English* (Italic, calligraphic and nostalgic)
- **Aesthetic Accents**:
  - Looping anti-gravity floating cards (`translateY` loops)
  - Interactive collections masonry grids with hover lifts
  - Organic fabric-noise overlay applied via inline SVG filters
  - Slow-moving silhouette drift (swan outlines, temple arches, petals)

---

## 🏗 Website Sections

1. **Sticky Navigation Bar**: Glassmorphic blur backing with expandable search field, active cart badge, and wishlist panel.
2. **Flash Sale Banner**: CSS-scrolling marquee ticker.
3. **Hero Section ("The Story Begins")**: Asymmetric layout showcasing floating product renders, poetry taglines, and drifting SVG shapes.
4. **Brand Story Strip**: Dark-olive banner highlighting Karigar craftsmanship and textile values.
5. **Collections Grid**: Asymmetric responsive cards with category tabs, quick look sliders, and immediate add-to-cart controls.
6. **Print Universe**: An interactive horizontal slider focusing on traditional block prints and custom folklore stories.
7. **Fabric Finder Quiz**: 3-step conversational questionnaire recommending custom fabric packages based on occasion, feel, and silhouette.
8. **Customisation Portal**: Artisan modification form for necklines, custom shades, or size specifications.
9. **About Us Section**: Split editorial showcasing Jaipur dyes and weaver statistics.
10. **Footer**: Deep maroon closure integrating WhatsApp/Instagram connections and newsletter signups.

## 🛠 Running the Website Locally

Since Node.js or Python dev environments are not configured on this mac, we structured this application to run **zero-install, zero-build, zero-server**.

To preview:
1. Locate the [index.html](file:///Users/manavijain/.gemini/antigravity/scratch/ishara-website/index.html) file inside the project directory.
2. Double-click it to open it in **Chrome, Safari, or Firefox** via the `file://` protocol.
3. All React component states (adding items to cart, wishlist updates, search query filtering, style quiz navigation, customisation submissions, quick view drawers) will work natively.
